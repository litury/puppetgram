# Русскоязычные источники парсера

`PARSER_SOURCE_LANGUAGE=ru` ограничивает только источники `parse:sources`. Значение `all` (по умолчанию) сохраняет прежний режим. Неизвестное значение останавливает запуск.

Из `parsed=false` детерминированно по ID выбираются кандидаты по названию и сохранённому описанию. Затем перед запросом рекомендаций читаются последние пять сообщений источника. Проверка использует преобладание русских букв, характерные слова и исключение характерных букв других кириллических языков. Нужны содержательный текст и большинство русскоязычных сообщений; ссылки, короткие подписи и отсутствие текста не подтверждают язык. Это консервативная эвристика, не гарантия страны или безошибочное определение языка. Источники с латинским названием без русского описания могут быть пропущены.

Неподтверждённые источники не запрашиваются на рекомендации и не помечаются спарсенными. В `channel_meta.parserSourceRuRetryAt` сохраняется отсрочка на семь дней, чтобы после рестарта не тратить запросы на те же неподходящие источники; остальные метаданные сохраняются. Статусы комментатора и проверки чатов не меняются. FLOOD_WAIT при чтении постов обрабатывается существующей ротацией, без сброса лимитов. Ошибка чтения не считается подтверждением русского языка.

Тематического фильтра нет. Найденные рекомендации сохраняются как раньше: Telegram может рекомендовать иностранные каналы даже для русского источника. Они не становятся источниками автоматически без того же отбора. Этот режим не фильтрует очередь чекера или комментатора.

Миграций и удаления каналов нет. Проверки: `npx ts-node src/scripts/utils/testRussianParserSources.ts`, `npx ts-node src/scripts/utils/testParserFloodPersistence.ts`, `npm run build`.
